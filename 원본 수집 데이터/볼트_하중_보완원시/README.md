# xArm 볼트 고정 실측 원시 데이터 보완

2026년 11월 11~12일 No.3 동작에서 작업자가 운반과 B→A 자동 원복을 확인한 24개 세션, 510회를 담았습니다. 베이스는 고정했고 ADXL345는 볼트와 너트로 장착했습니다.

| 캠페인 | 세션 | 정상 | A121 | B82 | C182 | 합계 | 원래 용도 |
|---|---:|---:|---:|---:|---:|---:|---|
| 11월 11일 A/B/C 교차 수집 | 13 | 90 | 30 | 30 | 30 | 180 | 동결 모델 평가 |
| 11월 11일 정상 확장 | 4 | 240 | 0 | 0 | 0 | 240 | 학습 120, 교정 60, 평가 60 |
| 11월 12일 B/C 독립 수집 | 7 | 30 | 0 | 30 | 30 | 90 | 고정 임계값 평가 |
| 합계 | 24 | 360 | 30 | 60 | 60 | 510 | |

정상은 프레임에 추가 하중을 부착하지 않은 41g 물체 운반입니다. A121은 프레임 추가 하중 없이 121g 물체를 운반한 조건입니다. B82와 C182는 41g 물체를 운반하면서 각각 상부 프레임에 82g, 하부 프레임에 182g을 추가한 조건입니다. `condition`은 이전 보완본과 같은 정상·A/B/C 분류이고 `label`은 각 캠페인 평가에서 사용한 상세 조건명입니다. `physical_outcome`은 작업자가 확인한 운반·원복 결과를 기록합니다.

| 파일 | 내용 |
|---|---|
| [`CAMPAIGN_SUMMARY.csv`](CAMPAIGN_SUMMARY.csv) | 캠페인별 세션 수, 조건과 용도별 회차 수 |
| [`SESSION_INDEX.csv`](SESSION_INDEX.csv) | 세션 ID, 날짜, 캠페인, 계획과 확인 회차 수, 원시 스트림 행 수 |
| [`CYCLE_MANIFEST.csv`](CYCLE_MANIFEST.csv), `sessions/<session_id>/cycles.csv` | 조건, 실제 결과, 원래 용도, 분석 및 원복 구간의 시각 경계 |
| `sessions/<session_id>/measurements.csv` | INA226 전류·전압·전력 및 계측 상태 |
| `sessions/<session_id>/adxl345_1.csv` | ADXL345 가속도 X/Y/Z와 FIFO·수신 상태 |
| `sessions/<session_id>/single_queries.csv` | 6개 서보의 개별 위치 응답 |
| [`FILE_MANIFEST.csv`](FILE_MANIFEST.csv) | 목록 자체를 제외한 배포 파일의 크기와 SHA-256 |

`source`는 각 목록 파일을 기준으로 한 상대 경로입니다. `No3_begin_ns`는 No.3 명령 송신 완료, `No3_end_ns`는 위치 기반 완료 대리판정의 호스트 단조 시각(ns)입니다. `action_begin_ns`와 `action_end_ns`는 같은 No.3 분석 창을 나타냅니다. B→A 자동 원복 구간은 `return_begin_ns`와 `return_end_ns`에 별도로 기록했습니다. 각 세션의 마지막 INA·ADXL 샘플은 마지막 원복 완료 표식보다 0.1초 이내 앞서 수신됐습니다.

정상 확장의 N01·N02는 학습, N03은 임계값 교정, N04는 같은 날 별도 시간 블록 평가입니다. 교차 수집과 독립 수집은 해당 모델 비교에서 평가에 사용했습니다. 교차 수집의 `pair_condition`은 하중과 직전 짝 정상을 연결합니다. B/C 독립 수집은 정상 30회 전체를 공통 대조군으로 사용했습니다. `leakage_group_id`는 같은 수집 캠페인의 시간상 연결된 세션을 묶습니다.

기존 v5.1의 INA 세션 ID 140개 및 Git LFS의 원시 CSV SHA-256과 대조했습니다. 배포 원시 CSV 72개의 바이트는 해당 캡처와 검증된 백업 ZIP의 CSV에 일치합니다. 11월 11일 전원 ON 휴지·스위치 OFF 휴지 비교 자료는 [이전 보완본](../V4_V51_보완원시/README.md)에 있습니다.
