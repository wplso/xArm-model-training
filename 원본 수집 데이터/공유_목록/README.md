# 공유용 xArm 수집 데이터

각 세션 폴더에 센서·서보 원시 CSV 세 종류와 회차 라벨·구간 CSV, 파일 설명 README가 있다.

- `1101 41g 정상 450회`는 기존 9개 블록이다.
- `정상`은 추가 1,431회다. 41g 운반, 무부하, 액션 번호, 고정 베이스 독립 평가를 분리했다.
- `이상`은 실험 기록 271회다. 확정 이상 270회와 E 실험 운반 성공 1회가 포함되어 있다. E의 성공 회차는 `confirmed_other_outcome`으로 표시했다.
- `세션_목록.csv`는 폴더별 조건과 회차 수, `회차_라벨.csv`는 전체 회차 ID, 라벨, 시작·종료 시각, 기존 학습·평가 이력을 담는다.
- 기존 독립 평가용 41g 20회는 적합이나 임계값 설정에 사용하지 않는다. 학습 및 평가 분할 시 같은 세션의 연속 회차를 고려한다.
