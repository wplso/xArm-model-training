| 11월 6일 볼트 장착 | 본수집 유효 399회, 추가 정상 17+13회, A/B/C 직전 정상 30/10/10회, A121·B상부82·C하부182 각 30회 |

## 파일 안내

| 파일 | 용도 |
|---|---|
| `SESSION_INDEX.csv` | 세션 ID, 상대 폴더, 날짜, 캠페인, 원본 상태 및 회차 수 |
| `CYCLE_MANIFEST.csv`, `sessions/<session_id>/cycles.csv` | 평가·학습에 사용할 수 있는 확인된 회차와 No.3 및 원복 시간 경계. `source`는 각 CSV의 위치를 기준으로 한 상대 경로 |
| `sessions/<session_id>/measurements.csv` | INA226 전체 DC 전류·전압·전력 및 상태 |
| `sessions/<session_id>/adxl345_1.csv` | 가속도 X/Y/Z 및 FIFO·수신 상태 |
| `sessions/<session_id>/single_queries.csv` | 6개 서보의 개별 위치 응답. 센서 전용 OFF 휴지에는 서보 파일과 회차가 없음 |
| `EXCLUDED_CAPTURE_CYCLES.csv` | 타임아웃이나 신선도 검사로 중단된 회차. 해당 원시 파일 전체를 보존했으므로 시간 경계 밖의 샘플을 라벨로 사용하지 않음 |
| `REST_EVENTS.csv` | 전원 ON 휴지의 수집기 시간 표식과 OFF 휴지의 INA 전류 기반 경계. 물리 스위치 시각은 직접 계측하지 않음 |
| `FILE_MANIFEST.csv` | 이 목록 자체를 제외한 배포 파일 크기와 SHA-256 |

`No3_begin_ns`는 명령 송신 완료 시각이며 `No3_end_ns`는 위치 기반 완료 대리판정 시각입니다. 모두 같은 PC 실행의 단조 시각(ns)입니다. `return_begin_ns`와 `return_end_ns`는 자동 원복 경계를 별도로 표시합니다. B→A는 No.3 분석 창에서 제외합니다. `payload_mass_g`는 지정 물체 질량이며 파지 실패나 이탈에서 실제 운반이 완료되었다는 뜻이 아닙니다. F의 물체 질량은 미기록입니다. A는 121g 운반, B는 41g 운반과 상부 82g, C는 41g 운반과 하부 182g, D는 처음부터 집지 못함, E는 들어 올릴 때 이탈, F는 물체가 닿지 않는 위치입니다.

테이프와 볼트 장착을 `sensor_mount`로 구분합니다. V4 본수집은 학습 200·교정 100·동일 연속 수집 홀드아웃 99를 유지합니다. 나머지 평가 자료는 해당 연구에 이미 사용되었으므로 새 모델의 미열람 독립 검증으로 해석하지 않습니다. 11월 11일 휴지 비교는 실험 이력의 영향이 있어 `study_only`로 분리했습니다. A 직전 볼트 정상 30회는 별도 수집 정상 30회이기도 하므로 한 번만 포함했습니다.

11월 5일 E의 20회는 세 시도의 확인된 완료 2+8+10회입니다. E 직전 정상 중 한 세션의 원본 폴더가 `normal_pre_D`인 것은 동작 전 조건 순서 변경 때문입니다. 본수집 b08 및 정상 17회 세션의 중단 회차도 라벨에서 제외했습니다. 11월 1일 마지막 50회는 파지 실패가 섞였고 경계가 불명확해 포함하지 않았습니다. 다른 진단·실패·혼합 세션, 이전 공유본과 같은 원시 데이터, 실행 로그, 장치 식별 정보, 학습된 모델 및 산출 점수는 이 보완본에서 제외했습니다.
