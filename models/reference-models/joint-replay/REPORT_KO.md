# xArm 고정 기준 모델 결합 재생 — 2026-11-14

주 분할 로지스틱 S2와 TabPFN-v2 S2 P0를 원래 평가 490회에서 각각 다시 추론했다. GRU F2·O3를 원래 평가 930회의 정렬 캐시에서 다시 추론하고, 원래 `ALL` 정책으로 실제 수신 시각 순서에 맞춰 잔차를 계산했다. 모델별 평가 역할의 교집합만 회차 ID로 연결했다. 정상 160회와 B82·C182·D·E·F·폼 접촉·작업대 흔들림 각 30회, 총 370회였다. 모든 회차에서 두 분류 점수와 GRU 감시 결과를 확보했다. A121은 공통 평가에 0회였다. [동결 모델 설정](../FROZEN_MODELS.json)

로지스틱과 TabPFN의 `1−P(normal)`에는 각각 **0.2907932588975627**, **0.19058864334053838**을, GRU의 정규화 잔차에는 원래 `ALL` 경계 **7.288925055167675**를 엄격한 `>`로 적용했다. TabPFN은 저장된 원본 가중치와 809회 학습 문맥을 사용했다. 기존 결과와 비교했을 때 두 분류기의 확률과 GRU 예측은 최대 절대 차이 0이었고, 세 모델의 경보와 GRU 첫 경보 시각도 모두 일치했다. [재생 검증](results/VERIFICATION.json)

## 정상 오탐과 유형별 탐지

각 셀은 경보 회차 수/평가 회차 수다. 이상 행은 해당 실제 유형에서 경보한 비율이다. OR는 한 회차에 두 모델 중 하나라도 경보하면 1건으로 집계한다. 분류기의 추정 하중 유형은 원본과 같이 별도로 기록했다.

|---|---:|---:|---:|---:|---:|
| 정상 오탐 | 4/160 (2.50%) | 0/160 (0.00%) | 3/160 (1.88%) | 6/160 (3.75%) | 3/160 (1.88%) |
| B82 상부 하중 | 29/30 (96.67%) | 29/30 (96.67%) | 1/30 (3.33%) | 29/30 (96.67%) | 29/30 (96.67%) |
| C182 하부 하중 | 29/30 (96.67%) | 30/30 (100%) | 3/30 (10.00%) | 29/30 (96.67%) | 30/30 (100%) |
| D 최초 파지 실패 | 0/30 (0%) | 10/30 (33.33%) | 30/30 (100%) | 30/30 (100%) | 30/30 (100%) |
| E 들어 올리다 이탈 | 0/30 (0%) | 20/30 (66.67%) | 30/30 (100%) | 30/30 (100%) | 30/30 (100%) |

두 조합에서 B82·C182의 GRU 경보는 모두 분류기 경보에 포함됐다. D·E·F·폼·흔들림은 GRU만으로 각각 30회 모두 감지했다. 로지스틱이 놓친 B1 12회차와 C1 1회차는 TabPFN이 잡았고, TabPFN이 놓친 B1 10회차는 로지스틱이 잡았다. 따라서 전체 탐지 건수 차이는 1건이지만, 이상 회차 판정은 3건이 달랐다. 이 차이는 11/12 캠페인에서 발생했다. [OR 판정이 다른 6회](results/OR_DISAGREEMENT_CYCLES.csv)

## 같은 회차에서의 경보 겹침

겹침은 같은 회차에 두 경보가 모두 기록된 경우다. 동작 중 잔차 경보와 회차 종료 판정은 각자의 시점에 발생한다.

| 실제 조건 | 로지스틱만 / GRU만 / 둘 다 | TabPFN만 / GRU만 / 둘 다 |
|---|---:|---:|
| 정상 | 3 / 2 / 1 | 0 / 3 / 0 |
| B82 | 28 / 0 / 1 | 28 / 0 / 1 |
| C182 | 26 / 0 / 3 | 27 / 0 / 3 |
| D | 0 / 30 / 0 | 0 / 20 / 10 |
| E | 0 / 30 / 0 | 0 / 10 / 20 |
| F | 0 / 30 / 0 | 0 / 12 / 18 |
| 폼 접촉 | 0 / 13 / 17 | 0 / 27 / 3 |
| 작업대 흔들림 | 0 / 26 / 4 | 0 / 30 / 0 |
| 이상 전체 | 54 / 129 / 25 | 55 / 99 / 55 |

로지스틱과 GRU의 정상 겹침은 11/10 전원 재가동 세션 38회차 1건이었다. GRU는 시작 4.30초에 처음 경보했다. 로지스틱 OR가 추가한 오탐 3건은 재가동 2·28회차와 11/13 흔들림 시험 뒤 정상 1회차였다. TabPFN OR의 정상 경보 3건은 모두 GRU 경보였다. [공통 370회 상세](results/CYCLE_ALERTS.csv) · [겹침 회차](results/OVERLAP_CYCLES.csv) · [집계 CSV](results/COMPARISON.csv)

이 재생에서는 TabPFN 조합이 정상 오탐을 6건에서 3건으로 줄이면서 이상 1건을 더 잡았다. 결과는 이미 열람한 No.3 회차의 회고 평가다. A121, 새 독립 캠페인과 Raspberry Pi 4B의 200ms 발행 성능은 별도 확인이 필요하다. OR는 이번 비교를 위해 계산했다.
