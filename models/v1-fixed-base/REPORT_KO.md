# xArm V1-베이스고정 정상 학습 및 이상 평가

## 분할과 비교 조건

고정 베이스 41g 자동 원복 450회를 수집 순서대로 b01~b05 학습 250회, b06~b07 정상 검증 100회, b08~b09 정상 평가 100회로 배정했다. 데이터 섞기나 검증·평가 회차의 전처리 적합은 하지 않았다. 특징 7종에 Statistical, Isolation Forest, PCA를 적용해 21개 모델을 학습했다. 기존 방식인 검증 정상 점수 95% 분위수(higher), score > threshold를 사용했다. 이전 정상 20회는 별도 평가에만 사용했다.

V2.1은 동일 Cycle의 저장 점수와 모델별 고정 임계값을 사용했다. A 82g 운반, B 상부 하중, C 하부 하중, D 처음부터 파지 실패, F 비접촉 위치 오류는 각각 30회다. E는 사용자 확인된 들기 중 이탈 29회다. E 30회차 운반 성공과 별도 이탈 파일럿 1회는 주 평가와 분리했다. D~F의 자동 원복 여부와 시작 자세는 정상 조건과 일부 다르며, 특징은 기존과 동일한 No.3 구간이다.

같은 수집의 후반 100회에서 A7 PCA는 V2.1 A/B 모두 100회 오탐에서 6회로 줄었다. A7 IF와 B5 IF도 각각 50회와 66회에서 5회로 줄었다. 별도 정상 20회에서는 A7 PCA가 1회로 안정적이었지만 A7 IF는 9회, A7 Statistical은 17회로 세션 차이가 남았다.

고정 임계값에서 하중 A·C 탐지율은 낮아졌다. 다만 같은 정상 후반 100회 대조에서 B3 IF는 A/B/C AUROC 0.873/0.969/0.831이었다. C를 2/30회만 탐지했으므로 점수 순위에 분리 신호가 있어도 현재 임계값에서 포착하지 못하는 경우가 있음을 보여준다. 임계값은 이상 평가를 보고 조정하지 않았다.

전류·전압에서 전류 표준편차를 뺀 C9 Statistical은 정상 4/100, 별도 정상 4/20, 상부 하중 23/30이며 D/E/F는 30/30, 29/29, 30/30을 표시했다. 82g 운반과 하부 하중은 각각 6/30, 2/30이다. 탐색 순위에서 이 모델의 평균 TPR−FPR이 높았지만, 하중 전체를 담당할 수 있다는 근거는 부족하다. B3 IF는 낮은 같은 세션 FPR과 하중 점수 분리도 때문에 대조 가치가 있으나 별도 정상에서 10/20 오탐했다. A7 PCA는 별도 정상과 D~F에서 유용한 대조 후보다.

## 검증과 적용 범위

21개 저장 모델을 다시 불러와 동일 점수를 확인했고 전처리·임계값의 학습/검증 역할과 기존 참조 임계값을 검사했다. 입력 파일 해시가 일치한다. 평가 100회는 같은 연속 수집의 후반 블록이며, 앞선 별도 정상 20회도 이미 분석한 세션이다. 이상 자료도 모델 비교에 사용한 탐색 자료이므로 독립 날짜 성능이나 운영 승격 근거로 사용하지 않는다.
