# xArm V3.1 하중 민감도 개발 평가

V3를 유지한다. V3.1은 18개 특징 구성의 Statistical·Isolation Forest·PCA 54개를 학습했다. 저장된 V3 33개와 V1-베이스고정 21개를 동일 데이터로 재평가했다.

## 데이터와 검증

788회는 고정 베이스 정상 학습 250, 검증 100, 홀드아웃 100, 별도 정상 20, 기존 이상 198, 신규 정상 40와 신규 이상 80으로 구성된다. 전처리는 학습 250회에서 적합했다. 정상 검증 100회의 q95(higher)를 초과한 경우를 이상으로 판정했다. 기존 A~F/B232는 별도 정상 20회를 우선 대조하며 홀드아웃 100회 비교는 분리했다. 신규 정상 10회와 이상 20회는 그룹 단위 대조다.

C182 최초 중단, C282 파일럿, C462 첫 미완료, B232 첫 미완료 및 E의 별도 파일럿·성공 회차를 제외했다. C462는 ID5 781±10, B232는 ID4 954±10 종료 정책을 사용했다. 신규 120회의 실제 운반·원복 확인 기록과 원시 UART/HID 감사를 확인하고 아카이브 해시·CRC를 대조했다. 원시 자료로 기존 23특징과 S3~S5, ID1 파지, 기타 V3 특징을 재현했다.

## C182의 순위와 경보

V3-D IF의 C182는 AUROC 0.980, 탐지 4/20, 짝 정상 오탐 0/10이다. 미탐 16회 가운데 13회는 짝 정상 q95보다 높았지만 검증 기준 임계값을 넘지 못했다. 이상 점수 중앙값과 임계값 차이는 -0.0306였다. 이 모델의 낮은 경보율에는 점수와 검증 기준 사이 간격이 직접 작용했다. S4의 작은 변화와 구성별 격차를 고려하면 입력과 점수 함수의 영향도 있다. 종합 후보는 13/20, AUROC 0.995였다. 짝 정상 q95는 해석에만 썼다.

## 해석 보충

- S4 평균은 단일 구간 후보 중 해석하기 쉬웠다. PCA에서 기존 23특징에 추가하면 A121은 3/20→6/20, C182는 5/20→8/20, 홀드아웃 FPR은 6/100→3/100이었다. 별도 정상은 1/20으로 같았다. 이 비교의 기준 모델은 R1 PCA다.
- S4 RMS의 학습 정상 순위 상관은 0.999였다. PCA에서 평균에 RMS를 더했을 때 A121과 C182가 모두 악화됐다. S4 표준편차와 P95는 PCA에서 A121을 각각 10/20, 12/20으로 개선했고 C182는 8/20으로 같았다. P95 조합은 정상 100회 5건, 별도 정상 20회 0건을 표시했으나 다른 정상 대조에서 최대 10%였다.
- V31-15 PCA는 V3-C-S34 PCA 대비 C182가 11→13/20, 홀드아웃 오탐이 13→6/100, 별도 정상 오탐이 0→1/20이다. A121은 모두 8/20, A193·C462는 모두 20/20이다. D·E·F는 유지됐으나 기존 A82·B82·C82는 모두 낮아졌다. V31-9 Statistical은 별도 정상 17/20 오탐으로 미세 하중 대조용이다.
- 8개 신규 블록의 원시 manifest에서 베이스 고정, B→A 자동 원복, 원복 전 300ms 유예를 확인했다. normal_a의 첫 회는 home, 나머지 신규 블록의 첫 회는 A_release였다. 질량별 물체의 형상과 파지 면이 동일했다는 검증은 없다. 종료 시각은 호스트 로그의 대리판정 시각이다.
