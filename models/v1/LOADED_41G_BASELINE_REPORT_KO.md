# 41g 운반 본수집 검증 및 정상 Baseline 비교

작성 시각: 2026-11-01T07:20:22.839080+09:00

## 먼저 볼 결과

No.3→B→A 복원은 **500회 계획대로 종료**했고, 수신 데이터의 누락·중복·통신 오류와 ADXL 인코딩 이상은 관측되지 않았다. 원본과 10개 ZIP 백업의 일치도 확인했다. 다만 사용자 추가 확인으로 **마지막 b10 구간 도중부터 블록을 집지 않고 무부하로 반복한 사실**이 확인됐다. 정확한 전환 회차는 알 수 없다. 따라서 500회를 모두 41g 정상 데이터로 쓰지 않는다.

최종 분류는 **41g 정상 확인 450회 = 학습 250 + 검증 100 + 같은 날짜 정상 평가 100**, **조건 불명확 50회 = b10 전체 격리**다. 마지막 50회를 통째로 보류한 근거는 사용자 관찰과 수집 블록 경계이며, 이상 점수로 유리한 회차만 선택한 것이 아니다. 학습·검증 구간은 정정 영향을 받지 않았으므로 모델과 임계값은 바꾸지 않고 저장 점수만 재집계했다.

|---|---|---:|---:|---:|---:|
| 전류·전압 6특징 | Statistical | 27 | 4 | 3 | 3% |

| 전류·전압+진동+위치 23특징 | PCA | 14 | 4 | 0 | 0% |

이는 정상 FPR 비교다. 실제 이상에 대한 AUROC·PR-AUC·Recall·F1이나 고장 원인 진단 성능은 아직 계산할 수 없다. 추가 시험과 새 수집은 이번 작업에서 실행하지 않았다.

각 No.3 내부에서 INA 실제 간격 기준 약 9.62~9.75Hz, ADXL 호스트 수신 기준 약 97.61~98.13Hz, 관절별 약 2Hz를 확인했다. 관절 최대 응답 간격은 약 0.514초였다. ADXL은 FIFO 묶음 수신이므로 호스트 시각을 정밀 샘플 발생 시각으로 해석하지 않는다. MCU·HID 사이 하드웨어 동기화는 하지 않았다.

원시 UART를 재파싱해 완결된 INA/가속도 CSV와 대조했고, 원시 HID 응답도 조회 ID·위치·시각과 대조했다. 모든 No.3과 B→A 6행 명령이 고정 명령과 일치했고, 첫 복원 명령 전 300ms 이상 유예 및 복원 중 위치 조회 없음도 확인했다. 위치 복귀 안정 대리판정은 모든 Cycle에서 재현됐다. 물체 운반 성공은 이 대리판정이 자동 인증하지 않는다.

캡처 시작의 부분 3줄과 종료의 미완결 57바이트는 원본에 보존됐고 유효 측정 행에 넣지 않았다. 이는 캡처 경계 제한이며 유효 sequence 중 누락 0건과 구분한다. UART에 모든 행을 보호하는 CRC가 있는 것은 아니다. 여기서 CRC 검증은 ZIP 아카이브 검사다. 비활성 ADXL2(0x1D)의 예상된 초기 ACK 오류 상태는 활성 ADXL1의 오류로 합산하지 않았다. 실제 계측 정확도 전체를 인증한 결과도 아니다.

## 물리 조건 정정과 데이터 사용 기준

최초 사용자 답변 “예”는 500회 정상 운반 확인 질문에 대한 응답으로 원형 보존했다. 이후 전류 변화를 발견해 재확인하자 “블록을 안 집은 채로 무부하 반복함”, “마지막 구간 도중부터, 회차 불명”으로 정정했다. **후속 정정을 최종 라벨의 근거로 사용**한다. 원본 수집 manifest와 summary의 `41g`, `pending operator review` 같은 당시 표시는 수정하지 않고 외부 검토 파일로 보완했다.

| 회차 | 블록 | 최종 역할 | 사용 여부 |
|---|---|---|---|
| 1~250 | b01~b05 | 41g 정상 학습 | 전처리·모델 적합 |
| 251~350 | b06~b07 | 41g 정상 검증 | 임계값만 결정 |
| 351~450 | b08~b09 | 같은 날짜 41g 정상 평가 | 정상 FPR 계산 |
| 451~500 | b10 | 41g/무부하 혼재·경계 미상 | 학습·정상 FPR·이상 Recall 모두 제외 |

b09→b10의 사이클별 전류 RMS 평균은 0.83398→0.57309A, 전압 평균은 7.80243→7.82770V로 바뀌었다. b10 평균제거 합성 가속도 RMS는 약 0.01775g로 b09의 0.01779g와 비슷했다. 451회와 452~454회 전류 패턴도 서로 달라 센서값만으로 정확한 실제 파지 시점을 확정하지 않았다. INA calibration=3200, config=17187은 10개 구간 전체에서 일정했다. 전류와 션트/5mΩ 환산 차이는 최대 0.00016A로 정수 양자화 수준이었다. 이 검사는 환산 일관성이며 별도 정확도 인증은 아니다.

따라서 처음 안내했던 평가 150회의 FPR 24.7~38.7%는 **조건 혼재를 정상으로 가정한 잠정 집계**로 폐기하고, 현재 표의 평가 100회를 사용한다. 기존 CSV는 변경 이력으로 보존한다. b10의 이상 표시율은 외부 Statistical/IF/PCA=48/50·48/50·33/50, 다중 센서=48/50·49/50·48/50이다. **개별 정답이 없어 이 값은 무부하 Recall도 정상 FPR도 아니다.** 통신 품질 통과와 실험 조건 유지를 별도로 확인해야 함을 보여준다.

## 모델과 평가 조건

입력 external은 전류 평균·RMS·표준편차·절댓값 p95와 전압 평균·표준편차의 6개다. multisensor는 여기에 가속도 XYZ 표준편차, Cycle 평균제거 합성 가속도 RMS·피크, ID1~6 실제 응답 raw 위치 범위·표준편차 12개를 추가한 총 23개다. 위치 raw를 각도나 목표 추종 오차로 만들지 않았다. 평균제거 가속도는 순수 진동이나 플랫폼 변위를 직접 측정하는 값이 아니다.

기존 특징 통계 함수와 Baseline 구현을 재사용했다. median 대치와 StandardScaler는 첫 250회에만 적합했다. Statistical은 표준화 특징의 제곱 평균, Isolation Forest는 200개 트리(seed 20261031), PCA는 학습 설명분산 95% 보존 후 재구성 MSE다. PCA 성분 수는 external 4개, multisensor 11개였다. 검증 100개 점수의 95% 분위수(`higher`)를 임계값으로 삼고 `score > threshold`에서 표시했다. 이 방식의 유한 표본 선택으로 검증 FPR은 모두 4/100이다. 목표 5%가 후속 데이터의 보장 FPR은 아니다.

무작위 회차 혼합 대신 사전 지정된 연속 수집 세션 분할을 유지했다. 전체 실험은 2026-11-01 같은 날짜다. 날짜 독립 평가로 표현하지 않는다. Cycle ID·session·질량 라벨·수집 역할·완료 소요시간은 모델 입력에서 제외했다. No.3 명령 완료부터 No.3 복귀 안정 대리완료까지만 요약했고 B→A 복원·휴지 구간은 넣지 않았다. 전체 사이클 종료 후 판정이며 실시간 조기 탐지 성능이 아니다.

학습 후 저장한 6개 모델을 다시 읽어 점수와 판정이 재현되는지 확인했다. 검증·평가에서 전처리 파라미터가 바뀌지 않는 것도 검사했다. 11개 오프라인 테스트가 통과했다. 후속 조건 정정 후에도 모든 모델 SHA256이 동일하며 재학습·임계값 변경·하이퍼파라미터 탐색은 하지 않았다. 과거 무부하 모델과 원시 파일도 보존했다.

## 해석과 다음 결정

다중 센서를 넣었을 때 FPR은 Statistical 3→6%, IF 5→9%, PCA 4→0%로 알고리즘에 따라 달랐다. 센서가 많으면 항상 불리하거나 유리하다고 결론 내릴 수 없다. 정상 변동, 서로 중복되는 특징, 표준화, 모델 점수 정의와 임계값이 함께 영향을 줄 수 있지만 이 비교만으로 원인을 분리하지는 못했다. 학습 데이터 자체에서도 다중 센서 IF의 표시가 58/250(23.2%)이므로 학습 정상 변동과 뒤쪽 검증 구간의 좁은 분포가 얼마나 다른지 향후 정상 세션에서 확인할 필요가 있다.

PCA의 평가 0/100은 100개 정상 자료에서 알람이 없었다는 뜻이다. 이상도 놓치는 모델인지 아직 모른다. CSV의 Wilson 95% 구간에서 0/100의 상한은 약 3.70%이며, 연속 반복의 상관성 때문에 일반화 불확실성은 더 클 수 있다. IF 9/100의 구간은 약 4.81~16.23%다. 정상 FPR만으로 최종 모델을 선정하지 않는다. 기존 방침대로 다중 센서 IF 계열을 비교 기준으로 유지하되, 새 41g 적합본과 외부 센서 참고 모델 등 6개 전부를 고정해 다음 조건을 동일하게 평가한다. Pi 배포 준비는 아직 하지 않는다.

상·하부 시험에서 물체를 운반하지 않으면 이번 41g 기준과 무부하 차이가 섞이므로 별도 조건으로 분리해야 한다. 같은 블록 2개를 부착한다면 명목 82g과 실제 두 블록+고정물 전체 질량을 구분한다. 82g 물체의 파지 폭·모양·놓기 위치가 바뀌면 순수 질량 효과와 구분해 기록한다. 조건 사이 41g 정상 대조를 두면 시간에 따른 변화를 판단하기 좋다. 정확한 횟수와 물리 준비는 다음 작업에서 정한다.

새 데이터는 고정 모델의 평가에 먼저 쓰며 결과를 보고 임계값을 맞추지 않는다. 정상 30회는 한 건당 3.33%p이므로 초기 점검에는 유용하나 정밀 FPR 추정은 어렵다. 본 실험 b10처럼 파지 상태가 불명확한 구간은 임의로 정상 라벨을 붙이지 않는다. 사용자 관찰/영상 등 실제 물체 운반 근거와 계측 품질을 별도 기록할 필요가 있다. 고장 유형 진단·미래 K-cycle 위험·RUL·voraus-AD에서 실제 장비로의 전이 성공은 이번 결과에 포함되지 않는다. 정밀 물리 종료 시각과 자연 timeout 복구의 실기 검증도 미완료 상태를 유지한다.
