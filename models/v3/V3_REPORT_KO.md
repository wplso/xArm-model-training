# xArm V3 동작 구간 특징 실험

## 1. 목적과 범위

No.3 전체 통계에 구간별 ID1 및 전류 특징을 추가하거나 기존 ID1 요약을 제거했을 때, 같은 검증 기준에서 정상 오탐과 하중·파지 이상 탐지가 어떻게 달라지는지 비교했다. 결과는 이미 특징을 탐색했던 자료의 오프라인 평가다.

## 2. 자료와 제외 기준

| 역할 | 자료 | 회차 |
|---|---|---:|
| 학습 | 고정 베이스 41g, b01~b05 | 250 |
| 정상 검증 | 같은 연속 수집, b06~b07 | 100 |
| 주 정상 평가 | 같은 연속 수집, b08~b09 | 100 |
| 별도 정상 평가 | 고정 베이스 41g 정상 20회 | 20 |
| 이상 평가 | A 82g 운반, B 상부 82g, C 하부 82g, D 최초 파지 실패, F 팔 도달 범위 밖 | 각 30 |
| 이상 평가 | E 들기 중 이탈 / 상부 232g B232 | 29 / 19 |

총 668회. E 30회차는 운반 성공, E 파일럿 1회는 별도 실험, B232 첫 시도는 위치 완료 판정에서 중단되어 제외했다. 베이스 고정 전 정상, 조건이 다른 과거 수집, 무부하 혼입 자료는 이 실험에 포함하지 않았다. A–C/B232와 정상은 자동 원복을 사용했다. D–F는 기본 자세 시작 및 자동 원복 없음이 공통이다. No.3 구간만 분석했어도 시작 자세·운전 이력이 달라 원인을 완전히 분리할 수 없다. 별도 정상 20회 중 기본 자세 시작은 1회라 자세 일치 비교로 일반화할 수 없다.

## 3. 특징 정의

- ID1 IQR과 max_step은 No.3 송신 완료 후 [3,5)초의 실제 응답으로 계산했다. 각각 Q75−Q25와 인접 관측값의 최대 절댓값 차이다. 응답 4개와 간격 0.75초 이하를 요구했다.
- S3/S4/S5 전류 평균은 각각 [3,4), [4,5), [5,6.5)초의 INA226 샘플로 계산했다. 각 8/8/12개 이상, 최대 간격 0.25초 이하, 시퀀스 연속 조건을 사용했다. 동작 구간은 호스트 시간 기준의 근사다.
- 전체 특징의 범위는 No.3 송신 완료부터 위치 기반 종료 판정까지다. B→A와 다음 회차 샘플은 특징 창에서 제외했다. 이 모델들은 회차 종료 기반 평가다.

## 4. 원시 특징 검증

원시 INA·ADXL1·HID CSV에서 668회 모두 기존 23개 특징을 재계산해 저장값과 대조했다. 이전 ID1 IQR 530회와 최대 변화량 80회도 일치했다. 별도 정상·A–F의 구간 전류 저장값 597개도 일치했다. 기본 ID1 창은 전체 668회에서 4개, 최대 인접 간격 0.508초였다. S3/S4는 각 9~10개, S5는 14~15개였고 핵심 신규 특징 결측은 0건이었다. 샘플 보간은 사용하지 않았다.

## 5. 기존 모델 재현

저장 모델 84개(V1 초기 기준 21개, V1-베이스고정 21개, V2.1 42개)를 원래 전처리와 임계값으로 채점했다. V1-베이스고정과 V2.1은 저장된 공통 Cycle 점수·판정을 대조했다. V3의 R0/R1은 대응하는 V1-베이스고정 A2/A7 6개와 668회 점수, 임계값, 판정이 모두 정확히 같았다. 이전 모델 및 입력 파일 175개의 해시를 작업 후 다시 검사했다.

## 6. 학습과 임계값

필수 9구성 × 3알고리즘 27개, S5 평균을 제외한 S34 대조 3개, S5 감소 시점 대조 3개로 총 **33개**를 학습했다. IF 200개 트리, seed 20261031, PCA 95% 설명분산, Statistical 표준화 제곱 평균을 유지했다. 중앙값 결측 대체 및 표준화·모델 적합은 정상 250회에서만 했다. 임계값은 정상 검증 100회의 95분위(higher), 판정은 score > threshold다. 모든 V3 모델의 검증 표시 수는 4/100이었고, 저장 후 재로딩 점수와 판정이 정확히 일치했다.

## 7. 특징별 Ablation

- IQR만 추가한 V3-A PCA는 R1 PCA 대비 A/B/C가 4/5/2회에서 **5/12/3회**로 늘었다. D/E/F는 이미 30/29/30으로 유지됐다.
- S3–S5만 추가한 V3-B IF는 R1 IF 대비 A/B/C가 5/14/1에서 **7/15/2회**로 늘었다. 별도 정상 오탐은 9→10/20이었다.
- V3-C IF에서 전체 ID1 range만 제거한 V3-D IF는 별도 정상 오탐 10→8/20, A/B/C 5/11/0→**9/19/2**였다. std까지 제거한 V3-E IF는 B 22/30으로 늘었지만 별도 정상 오탐도 12/20으로 늘었다. 다른 알고리즘까지 일괄 제거할 근거는 부족하다.

## 8. 정상 오탐

V3-A PCA는 후반 정상 5/100, 별도 정상 1/20이다. 두 후반 블록과 별도 정상 세션 중 최대 표시율은 6%였다. V3-D IF는 5/100과 8/20으로, 후반 블록 결과만으로 다른 세션 오탐을 판단할 수 없다. V3-C-S34 PCA는 후반 13/100과 별도 0/20이며, 최대 14%였다.

## 9. 유형별 탐지 성능

D/E/F는 대표 V3 모델에서 각 30/30, 29/29, 30/30이었다. R1 PCA와 외부 센서 R0 IF도 이 수준에 도달하므로 신규 위치 특징 단독의 탐지 개선으로 돌릴 수 없다. E의 ID1 IQR 중앙값 52.75 raw와 S3→S4 평균 전류 1.213→0.473A는 들기 중 이탈 기록과 부합하는 구간 변화다. 정확한 회차별 사건 시각을 측정하지 않아 이 수치를 사건 전후의 직접 측정으로 간주하지 않는다. F는 파지 부재와 공통된 응답을 잡을 수 있으며 물체 위치 원인을 분류하지 않는다. 유형별 AUROC·AP·Balanced Accuracy·TPR−FPR·Precision·F1·양성 비율은 정상 대조별 CSV로 제공한다.

## 10. 상부 82g·232g 비교

S3 평균 전류 중앙값 1.552→1.659A, 사이클 전류 RMS 0.897→0.959A였다. V3-D IF는 B 19/30과 B232 19/19, V3-A PCA는 12/30과 14/19, V3-C-S34 PCA는 14/30과 19/19였다. 두 하중은 별도 세션이고 B232에는 임시 ID4 복귀 허용폭이 적용됐다. 질량만 바꾼 같은 세션의 인과 비교는 아니다.

## 11. ID1 IQR과 max_step

| 3–5초 위치 특징 중앙값 | 정상 후반 | D | E | F |
|---|---:|---:|---:|---:|
| IQR (raw) | 0.75 | 12.00 | 52.75 | 11.25 |
| max_step (raw) | 2 | 48 | 61 | 45 |

IQR은 D/F에서 창의 첫 응답과 이후 유지 위치의 차이를 반영한다. V3-C→F 교체나 G 병용에서 알고리즘 전체에 걸쳐 이득이 일관되지 않았다. 두 특징의 Spearman 상관은 F 1.00, D 0.75, E −0.19로 사건마다 다르다. 창을 +100ms 옮기자 D/F IQR 중앙값이 0이 됐다. 약 3.01초의 첫 샘플이 제외되는 영향이므로, IQR을 후속 후보로 유지하되 시작 시각과 샘플 위상을 다른 날짜에서 확인해야 한다.

## 12. S3/S4/S5 전류의 효과

S3/S4/S5를 추가한 일부 IF·Statistical에서 A·B의 후반 정상 대비 AUROC와 탐지가 개선됐으나, 별도 정상에서 같은 이득이 유지되지 않았다. S5를 빼고 비교한 V3-C-S34 PCA는 V3-C PCA 대비 A/B/C가 2/3/1→10/14/4, 별도 정상 오탐 1→0/20, 후반 정상 오탐 8→13/100이었다. C S5는 별도 정상 대비 낮았지만(1.113 대 1.266A), 후반 정상(1.211A)과는 분포가 겹쳤다. C의 안정적인 탐지 개선은 확인되지 않았다.

## 13. 보조 특징

S5 감소 시점은 고전류 참조 [4.5,5.3), 저전류 참조 [6.5,6.9)의 각 중앙값 중간점을 기준으로, [5.2,6.6)에서 처음으로 두 표본 연속 하회한 시각이다. 실제 계산 창은 [4,7.2)다. 정상에서는 전부 계산됐지만 D/E/F는 각각 14/30, 9/29, 4/30만 정의됐다. V3-C-fall IF는 V3-C IF 대비 A/B/C 5/11/0→6/7/2, 별도 정상 10→11/20이었다. 재현은 가능하지만 보조 특징 채택 근거는 약하다.

ID4는 정상 학습의 No.3 기본 종료 위치 중앙값 954 raw와 마지막 실제 응답의 절대 차이를 기록했다. 종료 위치 중앙값은 정상 954, B 957, B232 960 raw였다. 기록된 정상 위치는 기존 종료 게이트가 제한하며 B232는 ID4 허용폭이 달랐다. 관측 창 종료 조건과 실제 하중 효과가 얽혀 있어 이번 모델 입력에서 제외했다. 955 raw 단회 조회값을 학습 기준으로 사용하지 않았다.

## 14. 알고리즘별 차이

Statistical V3-C의 별도 정상 오탐에서 평균 점수 비중은 X축 가속도 표준편차 34.4%, 평균 제거 벡터 RMS 19.1%, IQR 1.7%, S4 전류 4.6%였다. 후반 정상 오탐에서는 ID4 전체 표준편차가 24.0%로 가장 컸다. PCA는 3~17개 성분, 설명분산 95.2~97.4%를 보존했고 전체 성분 보존 구성은 없었다. V3-A PCA의 D/F 재구성 오차는 IQR 단독 항보다 기존 위치 그룹의 합이 더 컸다. IF는 재학습 Ablation으로 입력 효과를 비교했고, 점수 분리가 보여도 고정 임계값 탐지율은 낮을 수 있었다.

## 15. V1-베이스고정·V2.1 비교

같은 회차에서 V2.1 A7 IF B는 정상 오탐 50/100과 11/20, A/B/C 탐지 21/30·30/30·18/30이었다. V3-D IF는 두 정상 대조의 오탐을 줄였지만 A–C 탐지도 줄었다. V3-A PCA는 V1-베이스고정 A7 PCA보다 후반 정상 오탐 1회 감소, 별도 정상 오탐 동일, A/B/C 각각 +1/+7/+1회였다. V2.1과 V3의 정상 학습 자료가 다르므로 버전 차이 전체를 구간 특징의 효과로 해석하지 않는다.

## 16. 미탐과 한계

V3-D IF의 C 미탐 28회는 후반 정상 P95보다 높지만 임계값 이하 2회, 사용한 신규 특징이 검증 정상 Q05–Q95 밖인데 점수는 정상 P95 이내 16회, 점검한 신규 특징에 큰 이동이 없었던 10회였다. 이는 설명을 위한 우선순위 분류이며 실제 물리 원인 판정은 아니다. 정상과의 순위 차이는 고정 임계값 판정과 별도로 해석해야 한다. 파형 그림은 미탐 예시와 후반 정상 대표 회차를 겹친 것이며 짝지은 실험 자료는 아니다.

## 17. 후속 후보와 독립 검증

1. **V3-A PCA**는 IQR 하나로 기존 PCA의 낮은 정상 오탐을 유지하면서 상부 82g 탐지를 개선한 우선 개발 후보다.
2. **V3-D IF**는 ID1 전체 범위 대체를 확인할 대조 후보다. 별도 정상 8/20 오탐이 있어 운영 전환 근거는 부족하다.
3. **V3-C-S34 PCA**는 A/B 탐지와 별도 정상 0/20의 절충을 확인할 하중 대조 후보다. 후반 정상 13/100 오탐 때문에 우선 운영 모델로 쓰기 어렵다.

운영 기준은 이번 실험으로 변경하지 않는다. 다음에는 고정 상태와 시작 자세·자동 원복이 같은 별도 날짜의 정상 41g과 하중 조건을 짝지어 확보한 뒤, 후보와 임계값을 고정해 평가한다. A·C 증량은 별도 후속 실기다.
