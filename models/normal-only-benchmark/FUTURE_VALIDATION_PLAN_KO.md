# 후속 미열람 평가 설계

평가를 다시 진행하게 되면 수집 전에 모델 파일과 전처리 해시, 입력 24개 순서, 점수 방향, 임계값과 초과 판정을 기록한다. 이번 실험의 649회와 직전 비교·재가동 진단에 사용된 회차는 개발 자료로 표시한다.

| 평가 단위 | 새로 확보할 조건과 기록 |
|---|---|
| 날짜별 정상 세션 | 고정 베이스, 볼트·너트 ADXL 장착, No.3, 같은 41g 블록·시작 자세·자동 원복. 전원·휴지·누적 운전 이력을 세션 메타데이터에 기록 |
| 재가동 정상 세션 | 첫 회차부터 포함. 1~10·11~20·21~30·31~40회와 전체를 함께 표시 |
| A121·B82·C182 | 같은 장착과 운반 경로의 정상 대조를 각 이상 조건에 연결. 물체 또는 프레임 하중·위치·실제 운반 성공을 기록 |
| 품질 및 분리 | 사용 전 세션과 회차 ID를 확정. 통신·파지·원복 실패 등 품질 사유를 사전 기준으로 기록하고, 품질 판정과 모델 경보를 구분 |

정상은 회차수와 FP, 세션별·동일가중·최악 FPR을 함께 보고한다. 하중은 각 조건 TP와 짝 정상 FP, AUROC와 AP를 분리한다. 같은 회차에서 기존 V4와 경보가 달라진 수를 보고한다. 평가 결과를 본 후 특징이나 임계값을 바꾸면 해당 자료는 개발에 사용한 것으로 이력을 갱신한다. 필요한 표본과 독립 세션 수는 실제 재수집 전 결정한다. 새 볼트 장착에서 D/E/F 작업 실패를 검증하려면 하중 평가와 별도 설계가 필요하다.

이번과 같은 입력으로 하중과 정상 변동의 겹침이 남으면, 후속 연구는 아래 질문을 구분해 설계할 수 있다.

- 현재 센서로 동일한 운전 상태의 정상과 하중을 얼마나 분리할 수 있는가?
- 이미 알려진 이상 라벨을 학습에 사용하면 알려진 조건을 구분할 수 있는가?
- 명령 구간·운전 이력·센서 시계열을 사용하면 원시 변동과 상태 차이를 구분할 수 있는가?
- 추가 온도나 전원 계측을 실측할 수 있다면 상태 변화의 설명력이 개선되는가?
