# 후속 독립 평가 후보 결정

**이번 비교에서 새 후보를 선정하지 않았다. V4 PCA Q를 비교 기준으로 유지한다.**

같은 649회에 사전 설정을 적용했을 때, 새 모델 중 전체 정상 오탐 45/259 이하, 재가동 오탐 23/40 미만, A121·B82·C182 탐지 각각 10·12·21/30 이상을 동시에 만족한 구성이 없었다. 다른 정상 세션의 악화도 세션별 표에 별도로 표시했다.

| 구성 | 이번 개발 비교에서의 판단 |
|---|---|
| LOF_K20 | C182 순위 분리는 회복했지만 재가동 오탐이 늘고 세 하중의 고정 경계 탐지가 감소했다. |
| OCSVM_G1 | 재가동 오탐은 23→20회, C182 탐지는 21→23회였다. 전체 오탐은 45→52회로 증가하고 A121·B82 탐지는 10→5회와 12→5회로 감소했다. |
| KNN_K20_MEAN | C182 점수 분리는 있었으나 전체·재가동 오탐이 늘고 세 하중 탐지가 감소했다. |
| LOF_K10·K40 | 이웃 수를 바꿔도 전체·재가동 오탐이 V4보다 높고 하중 탐지가 감소했다. |
| OCSVM_G025·G4 | G025는 전체·재가동 오탐을 줄였으나 세 하중 탐지가 감소했다. G4는 C182 탐지를 유지했으나 오탐이 늘고 A121·B82 탐지가 감소했다. |

저장한 새 모델은 이번 비교의 재현용이다. 두 보조 분할의 정상·이상 결과는 서로 다른 적합 모델이므로 운영 성능으로 합산하지 않는다. [성능 및 근거](ALGORITHM_COMPARISON_REPORT_KO.md) · [동결 후보 명세](FROZEN_RESEARCH_CANDIDATES.json) · [후속 미열람 평가 설계](FUTURE_VALIDATION_PLAN_KO.md)
