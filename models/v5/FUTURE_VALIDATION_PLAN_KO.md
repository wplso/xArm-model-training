# V5 동결 후 독립 검증 계획

V4의 기준 모델과 V5 개발 후보의 해시, 특징 순서, 전처리, 정책별 임계값을 검증 전에 고정한다. 같은 장착 조건에서 새로 수집한 미열람 자료를 이 상태로 평가한다. 이번 V5에 사용한 기존 Test99, 11월 10일 정상40회, 기존 A/B/C는 설계와 비교에 열람한 개발 자료다.

## 데이터 역할

| 구분 | 수집 또는 사용 원칙 |
|---|---|
| 동결 평가용 정상 | 날짜와 전원·운전 이력이 기록된 여러 독립 세션. 각 세션의 첫 회차부터 전체를 보존하고 시작 자세를 기록한다. |
| 동결 평가용 이상 | 동일 볼트·너트 장착, No.3 경로와 동일한 수집 설정. A121·B82·C182의 새 이상과 각각의 정상 대조를 사전에 짝지어 확보한다. |
| 작업 실패 검증 | 새 볼트 고정 D/E/F는 현 연구에서 미검증이다. 같은 장착 조건의 별도 정상 대조와 함께 평가하고, 몬스터겔 결과와 구분한다. |
| 후속 학습·교정용 정상 | 동결 검증 이후 새 교정 연구를 할 때만 별도 역할로 확보한다. 여러 정상 세션의 상위 점수를 비교할 수 있도록 학습·교정·미열람 평가 세션을 수집 전에 구분한다. |

한 연속 운전의 블록과 프로그램 재시작을 새로운 독립 날짜로 세지 않는다. 전원 재인가와 장치 재시작은 서로 다른 기록으로 관리한다. 시작 자세, 원복, 센서 장착·방향과 온도 또는 운전 경과를 가능한 범위에서 기록한다.

## 비교 기준

- 평가 정상 전체 및 세션별 FP/n, 세션 동일가중 평균, 최악 세션과 그 분모를 함께 제시한다. 동일한 정상 세션과 하중별 대조에서 V4와 동결 후보를 비교한다.
- A와 B의 TP/n을 우선 확인하고 C, Macro-AUROC, AP 및 경보 회차 차이를 함께 보고한다. 특징 간 중복을 줄인 구성은 D/E/F에서 작업 실패를 계속 감지하는지도 확인한다.
- 전체와 시작 자세·초반 구간의 결과를 같이 확인한다. 정상 고점수를 모델 점수만 보고 제외하거나, 조건마다 다른 임계값을 적용하거나, 평가 자료로 경계를 재설정하지 않는다.
- 새 다중 세션 교정의 효과를 비교하려면 이번 모델을 고정 대조로 유지한다. 독립 검증을 먼저 끝내고, 이미 열람한 자료를 이후 학습에 쓴다면 그 이력을 남긴 뒤 다시 미열람 평가를 확보한다.

후속 실험의 수행 시점과 실제 장치 사용은 별도 범위다.
