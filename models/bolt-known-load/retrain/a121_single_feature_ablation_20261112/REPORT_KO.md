# A121 단일 특징 제거 실험

기존 24개 특징 정상 확장 볼트 모델에서 Z축 가속도 표준편차, ID6 위치 표준편차, ID1 그리퍼 3~5초 IQR을 각각 한 개씩 빼고 23개 특징으로 따로 학습했다. 기존 볼트 학습 140회와 N01·N02 정상 120회, N03 정상 교정 60회, N04 정상 홀드아웃 60회를 그대로 사용했다. 전처리·분류기 설정은 유지했고, 새 모델마다 N03의 상향 95분위와 엄격한 초과 판정을 사용했다. 세 새 모델의 N03 오탐은 각각 2/60회였다. 기존 모델·임계값은 해시와 회차별 점수 재현으로 검증했다. A121 짝 정상은 40회이며 하중은 30회다. 어느 단일 제거도 기존 볼트의 A121 AUROC 0.736에 근접하지 못했다. Z축 제거는 통합 AUROC를 0.580에서 0.582로 바꿨고, 가장 약했던 A2와 N0 교차 비교는 0.320→0.420으로 개선했다. 동시에 A1 대 직전 정상은 0.611→0.544, A2 대 직전 정상은 0.873→0.840으로 낮아졌다. 고정 임계값에서 A121 경보가 2→3회로 늘었으며 신규 정상 오탐도 1→10회로 늘었다. [블록별 AUROC](A121_BLOCK_AUROC.csv)

ID6 제거는 A121 분리와 신규 정상 오탐이 거의 같았고 C182를 한 회 더 탐지했다. ID1 IQR 제거는 B82·C182 경보를 각각 10회·6회 늘렸고, 신규 정상 오탐은 1→3회로 늘었다. A121 AUROC는 0.567로 낮아졌다. B82·C182 짝 정상 대비 AUROC는 ID1 IQR 제거에서 0.965·0.988로 24특징 기준 0.967·0.988과 가까웠다. Z축 제거에서는 B82 AUROC가 0.967→0.993으로 높아졌고 C182는 0.988→0.893으로 낮아졌다.
