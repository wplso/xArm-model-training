# 정상 확장 재학습 후 A121 점수 분리 감소

이전에 평가한 A121 30회와 직전 짝 정상 40회에 두 저장 모델을 다시 적용했다. 두 모델에 동일한 24개 특징과 회차를 넣어 보존된 점수·확률·경보·유형을 재현했다. 학습과 임계값은 변경하지 않았다. 결과의 적용 범위는 이전 개발 평가 자료다. [재현 검증](VERIFICATION.json)

## 경보 순위와 점수 간격

|---|---:|---:|
| 짝 정상 대비 AUROC | 0.736 | 0.580 |
| A121 점수가 더 높았던 A121–정상 쌍 | 883/1,200 | 696/1,200 |
| A121 / 정상 점수 중앙값 | 0.836 / 0.253 | 0.061 / 0.048 |

점수 순서가 A121 우위에서 정상 우위로 바뀐 쌍은 249개, 반대로 바뀐 쌍은 62개였다. 두 모델에서 동점은 없었다. AUROC는 임계값을 적용하기 전 순위를 사용한다. 새 후보는 임계값이 0.864310에서 0.821445로 낮아졌는데도 A121 점수와 정상 점수의 순위 분리가 약해졌다. [점수와 지표](METRICS.csv) · [회차별 점수](A121_PAIRED_NORMAL_SCORES.csv)

## 분리가 약해진 특징

아래 수치는 A121과 짝 정상의 평균 차이에 대한 기여다. 유형 로짓은 `log(P(A121)/P(정상))`으로, 원래 단위의 평균 특징 차이에 표준화 배율까지 반영한 계수를 곱했다. 실제 경보 로그오즈는 `log((1−P(정상))/P(정상))`으로, 세 하중 유형을 합산한다. 정상에서 A121까지 각 1,200개 쌍의 직선 경로에서 기울기를 적분하고 평균을 냈다. 두 분해에서 특징별 합계와 실제 로그오즈 차이가 일치했다.

| 특징 | A121−정상 원단위 평균 차이 | A121−정상 유형 로짓 기여, 기존 → 확장 | 실제 경보 로그오즈 기여, 기존 → 확장 |
|---|---:|---:|---:|
| Z축 가속도 표준편차 | +0.000103g | +0.021 → −0.466 | −0.012 → −0.478 |
| ID6 위치 표준편차 | +0.294 raw | +0.499 → +0.149 | +0.367 → +0.091 |
| ID1 그리퍼 3~5초 IQR | +0.090 raw | +0.410 → +0.147 | +0.328 → +0.085 |
| ID3 위치 범위 | +0.300 raw | −0.224 → −0.442 | −0.173 → −0.391 |
| 평균 제거 가속도 벡터 RMS | +0.000862g | +0.051 → −0.155 | +0.025 → −0.185 |
| ID2 위치 표준편차 | +0.074 raw | +0.957 → +0.773 | +0.735 → +0.545 |

Z축 표준편차의 유형 로짓 계수는 0.001g 증가당 +0.206에서 −4.510으로 바뀌었다. 학습 당시 A121 평균은 0.00580g이었고, 기존 학습 정상 평균 0.00575g에 비해 새로 더한 정상 평균은 0.00641g이었다. ID1 IQR 역시 A121 학습 평균 0.658 raw는 그대로였지만 추가 정상은 0.358 raw로 기존 정상 0.160 raw보다 높았다. IQR 1 raw의 유형 로짓 효과는 +4.575에서 +1.646으로 약해졌다. ID6 표준편차의 효과는 1 raw당 +1.700에서 +0.508로 줄었다. 이 변화는 다변량으로 학습한 계수와 관측된 특징 분포의 관계를 설명한다. 개별 특징의 물리 원인을 확인하는 실험과는 범위가 다르다.

기여를 센서 그룹별로 합산하면 실제 경보 점수 간격 감소분은 위치 −0.738, 진동 −0.214, 전압 −0.064, 전류 −0.039 로그오즈였다. 기존 모델에서 맞았던 순위를 새 모델이 뒤집은 249개 쌍에 한정하면 Z축 표준편차 −1.955, ID6 위치 표준편차 −0.767, ID1 IQR −0.738의 감소가 두드러졌다. [특징별 원단위와 기여](FEATURE_GAP_ATTRIBUTION.csv) · [센서 그룹 기여](SENSOR_GROUP_GAP_ATTRIBUTION.csv)

## 어느 시간 블록에서 분리가 약해졌나

| A121 블록 / 정상 블록 | 비교 쌍 | AUROC 기존 → 확장 | 평균 경보 로그오즈 차이 기존 → 확장 |
|---|---:|---:|---:|
| A1 / 직전 N0 | 450 | 0.760 → 0.611 | +2.595 → +1.442 |
| A2 / 직전 N5 | 150 | 0.753 → 0.873 | +1.918 → +2.418 |
| A1 / 다른 시점 N5 | 150 | 0.827 → 0.973 | +3.083 → +4.845 |
| A2 / 다른 시점 N0 | 450 | 0.676 → 0.320 | +1.430 → −0.985 |

통합 AUROC에는 서로 다른 시점의 정상과 A121 비교도 포함된다. A2는 직전 N5와 비교하면 순위가 개선됐고, 첫 정상 N0와 비교하면 크게 약해졌다. 새 모델 점수 중앙값은 A2 0.0248, N0 0.0797, N5 0.00253이었다. A2와 N0에서 평균 경보 로그오즈 차이를 가장 크게 줄인 특징은 Z축 표준편차 −1.918과 ID6 표준편차 −0.703이었다. A2와 N5에서는 X축 표준편차 +0.688, ID1과 ID4의 전체 위치 표준편차 각각 약 +0.260이 차이 개선에 기여했다.
