# 정상 확장 볼트 모델의 오프라인 임계값 비교

동일한 저장 점수에서 재학습 모델의 임계값 0.821445와 가상 임계값 0.80~0.10을 0.05 간격으로 비교했다. 경보 기준은 점수가 임계값을 초과할 때다. 신규 정상은 학습·교정에서 분리한 당일 N04 60회이며, 하중은 이미 분석한 이전 캠페인의 조건별 30회다. 두 모델의 파일 해시를 검증하고 각 고정 임계값의 기존 경보를 재현했다. 아래 가상 임계값은 이번 점수표의 민감도 비교에 사용했다. [전체 비교표](THRESHOLD_SWEEP.csv) · [그래프](THRESHOLD_SWEEP.png)

| 모델·임계값 | 신규 정상 오탐 | A121 탐지 | B82 탐지 | C182 탐지 |
|---|---:|---:|---:|---:|
| 기존 볼트 0.864310 | 8/60 (13.3%) | 12/30 | 24/30 (80.0%) | 23/30 (76.7%) |
| 재학습 0.821445 | 1/60 (1.7%) | 2/30 | 13/30 (43.3%) | 8/30 (26.7%) |
| 재학습 0.70 | 1/60 (1.7%) | 2/30 | 16/30 (53.3%) | 15/30 (50.0%) |
| 재학습 0.60 | 3/60 (5.0%) | 2/30 | 19/30 (63.3%) | 19/30 (63.3%) |
| 재학습 0.55 | 3/60 (5.0%) | 3/30 | 23/30 (76.7%) | 20/30 (66.7%) |
| 재학습 0.40 | 5/60 (8.3%) | 4/30 | 25/30 (83.3%) | 22/30 (73.3%) |
| 재학습 0.30 | 11/60 (18.3%) | 6/30 | 25/30 (83.3%) | 23/30 (76.7%) |

0.70에서 신규 정상 오탐은 1회로 같았고, B82는 3회, C182는 7회 더 잡혔다. 0.40에서는 기존 볼트 모델 대비 신규 정상 오탐이 3회 적고, B82가 1회 많고 C182가 1회 적었다. A121은 4회였다. C182를 기존과 같은 23회까지 탐지한 0.30에서는 신규 정상 오탐이 11회였다. A121을 기존의 12회까지 잡은 0.10에서는 신규 정상 오탐이 29/60회였다.

정상 오탐과 하중 탐지 수치는 해당 데이터에서 관측한 결과다. 같은 평가표에서 여러 값을 비교했으므로 다른 세션에서의 오탐률과 하중 탐지율은 별도 확인이 필요하다. 기존·재학습 모델과 저장 임계값은 그대로다.
