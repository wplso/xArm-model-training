# 볼트 모델의 하중 점수 분리와 고정 임계값

11월 11일에 이미 분석한 하중 캠페인에서 두 모델이 점수를 낸 같은 회차를 비교했다. 하중은 조건별 30회이며, AUROC의 짝 정상은 직전 정상 블록에서 A121 40회, B82·C182 각 20회다. 점수는 하중 세 유형을 합한 `1−P(정상)`이다. 경보 조건은 저장된 임계값 초과이며, 기존 모델 0.864310, 재학습 모델 0.821445를 사용했다. AUROC는 임의의 하중 회차가 짝 정상 회차보다 높은 점수를 받는 빈도이며 동점은 절반으로 계산했다. 두 모델 파일 해시와 원본 점수·임계값을 확인하고 저장된 AUROC와 경보 횟수를 재현했다. [점수 분포 그림](SCORE_DISTRIBUTIONS.png) · [수치표](SCORE_DISTRIBUTIONS.csv)

| 하중 | AUROC 기존 → 재학습 | 하중 점수 중앙값 기존 → 재학습 | 짝 정상 점수 중앙값 기존 → 재학습 | 탐지 기존 → 재학습 |
|---|---:|---:|---:|---:|
| A121 | 0.736 → 0.580 | 0.836 → 0.061 | 0.253 → 0.048 | 12/30 → 2/30 |
| B82 | 0.935 → 0.967 | 0.976 → 0.757 | 0.377 → 0.002 | 24/30 → 13/30 |
| C182 | 0.920 → 0.988 | 0.966 → 0.695 | 0.311 → 0.008 | 23/30 → 8/30 |

**A121의 점수 분리는 약해졌다.** 재학습 후 하중 중앙값 0.061과 정상 중앙값 0.048이 가까웠다. 중간 50% 범위도 하중 0.018~0.216, 정상 0.004~0.109로 겹쳤다. 정상 최고점 0.869보다 높은 하중은 2/30회였으며 그 두 회차는 이미 경보됐다. 임계값 미달과 점수 순위 분리 저하가 함께 나타났다.

**B82의 점수 분리는 개선됐고 고정 임계값에서 탐지가 줄었다.** 재학습 후 짝 정상 최고점 0.619보다 높은 하중은 19/30회였다. 이 중 13회가 임계값을 넘었고 6회는 짝 정상 전부보다 높은 점수로도 미경보였다. 나머지 미탐 11회는 일부 짝 정상과 점수 범위가 겹쳤다.

**C182는 고정 임계값 미달의 영향이 가장 뚜렷했다.** 재학습 후 짝 정상 최고점 0.301보다 높은 하중은 23/30회였다. 경보는 8회였고, 미탐 22회 중 15회가 짝 정상 전부보다 높은 점수를 받았다.

B82·C182는 재학습 후 하중 점수도 낮아졌지만 짝 정상 점수가 더 크게 낮아져 순위 분리가 개선됐다. 짝 정상 최고점 비교는 이 평가에서 관측한 점수 분포를 설명한다. 새 임계값을 제안하거나, 다른 세션의 오탐률을 추정하는 데 사용하지 않았다.
