# 2026-11-11 xArm 볼트 고정 교차 순서 독립 평가

## 수집과 품질

정상 90회와 하중 A121·B82·C182 각 30회를 모두 평가했다. 하중은 조건별 15회씩 A1→B1→C1, B2→C2→A2 순서로 배치했다. A121은 121g 물체 운반, B82는 41g 운반과 상부 82g 부착, C182는 41g 운반과 하부 182g 부착이다. 정상은 프레임 추가 하중 없는 41g 운반이다. 작업자가 13개 블록의 실제 운반·원복을 모두 확인했다.

13개 블록의 원시 UART·HID 기록과 CSV, 백업 내용 및 해시 검증을 통과했다. INA·ADXL 시퀀스 누락, 위치 누락·타임아웃, ADXL 인코딩 이상, ID1 3~5초 IQR 결측은 각각 0건이었다. 원시 매니페스트 일부에 남은 이전 단계 설명은 캠페인 문서에 정정했고, 평가는 각 단계의 구조화된 조건을 사용했다. 세 모델과 임계값은 동결본을 사용했고, 180회는 모두 평가 전용이다. [평가 목록](EVALUATION_MANIFEST.csv) · [검증 결과](VERIFICATION.json)

볼트 학습은 몬스터겔 학습 대비 A121을 8회, B82를 1회 더 탐지했고 C182 탐지 횟수는 같았다. 정상 오탐은 12회 늘었다. 같은 회차를 대응해 보면 정상 13회에서 볼트 모델만 경보했고, 정상 1회에서는 몬스터겔 모델만 경보했다. 볼트 모델의 정상 경보 14회 중 12회는 A121로 분류됐다.

정확한 하중 유형까지 맞춘 횟수는 몬스터겔 모델의 A/B/C 2/23/23회, 볼트 모델의 12/12/20회였다. 볼트 모델은 B82 24회에 경보했고 그중 12회를 A121로 분류했다. V4 PCA-Q는 이상 경보만 평가한다. [하중별 지표](PAIRED_LOAD_METRICS.csv) · [유형 혼동행렬](TYPE_CONFUSION.csv) · [회차별 경보 변화](PAIRED_MODEL_CHANGES.csv)

A121에서 볼트 학습의 탐지 증가가 두 블록에서 같은 크기로 나타났다. C182는 두 로지스틱 모두 두 번째 블록의 탐지가 줄었다. 각 하중 바로 전의 정상 블록을 합친 짝 정상은 A 40회, B 20회, C 20회다. 마지막 N6는 전체 정상 오탐률에 포함하며 A2 직후 정상으로도 표시한다. [전후 정상 오탐과 하중 블록별 탐지](LOAD_BLOCK_AND_NEIGHBOR_METRICS.csv)
