# xArm V4 PCA Q · IF · PCA+IF 고정 분할 비교

**재가동 정상 오탐을 줄이면서 A121·B82·C182 탐지를 유지한 구성은 없었다.** IF 단독은 재가동 오탐을 23→11회로 줄였으나 세 하중의 탐지율이 모두 낮아졌다. 주성분 13개와 Q를 함께 사용한 IF는 단독 IF보다 C182를 더 많이 탐지했지만 기존 V4 대비 재가동 오탐이 같고 세 하중의 탐지는 낮았다. V4 PCA Q를 비교 기준으로 유지한다.

## 비교 조건

볼트 장착 V4의 같은 24개 특징과 정상 **학습 200 / 교정 100 / 기존 홀드아웃 99회**를 사용했다. 동일 V5.1 회차 목록의 후속 정상 160회와 A121·B82·C182 각 30회는 평가에만 사용했다. 정상 평가 합계는 중복 없이 259회다. 본수집 홀드아웃 99회는 학습과 같은 연속 운전의 후반이다. 준비구간을 포함한 기존 전체 범위를 평가했고, 재가동 11~40회는 같은 점수의 하위 집계로 함께 표시했다.

| 모델 | 입력 및 적합 |
|---|---|
| V4 PCA Q | 저장된 중앙값 대치, 표준화, 13개 주성분 및 기존 임계값을 그대로 사용 |
| IF 단독 | 같은 저장 전처리로 처리한 24개 특징으로 IF 적합 |
| PCA+IF | 같은 V4 PCA의 비백색화 주성분 좌표 13개와 Q 1개로 IF 적합. Q 사전 필터 없이 모든 회차를 점수화 |

두 IF는 정상 학습 200회, 트리 200개, seed 20261031, `-score_samples`를 사용했다. 같은 정상 교정 100회의 점수에서 각각 95분위수(`higher`)를 계산했다. 경보 조건은 세 모델 모두 `score > threshold`이며 교정 구간에서 모두 4/100회가 초과했다. 임계값은 PCA Q **0.07929062**, IF 단독 **0.55532880**, PCA+IF **0.52245568**이다. ## 고정 임계값 결과

| 모델 | 전체 정상 오탐 | 기존 정상 홀드아웃 | 11월 10일 첫 정상 | 재가동 전체 | 재가동 11~40회 | A121 탐지 | B82 탐지 | C182 탐지 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| V4 PCA Q | **45/259** | 10/99 | 5/40 | **23/40** | **15/30** | **10/30** | **12/30** | **21/30** |
| IF 단독 | **26/259** | 3/99 | 9/40 | **11/40** | **7/30** | **1/30** | **3/30** | **2/30** |
| PCA+IF | **51/259** | 6/99 | 17/40 | **23/40** | **15/30** | **2/30** | **5/30** | **14/30** |

- IF 단독은 재가동 11~40회에서 V4 오탐 10회를 해소했고 2회를 새로 경보했다. 다만 11월 10일 첫 정상 40회의 오탐은 5→9회였다. A121·C182는 기존 탐지 중 각각 9회·19회를 잃었고, B82는 기존 탐지 12회를 잃고 다른 3회를 새로 탐지했다.
- PCA+IF는 재가동 11~40회에서 V4 오탐 5회를 해소하고 다른 5회를 새로 경보했다. 특히 21~40회는 **10→13/20회**로 늘었다. C182는 기존 탐지 10회를 잃고 다른 3회를 추가 탐지해 21→14회가 됐다. [회차별 점수](results/CYCLE_SCORES.csv) · [같은 회차의 경보 전환](results/PAIRED_TRANSITIONS.csv)

## 점수 순위 비교

각 하중 30회와 연결된 41g 정상(A 30회, B 10회, C 10회)에서 계산했다. 같은 조건 안에서의 모델 비교다. [짝 정상 오탐·AUROC·AP](results/PAIRED_CONDITION_RANKING.csv)

| 모델 | A121 AUROC | B82 AUROC | C182 AUROC |
|---|---:|---:|---:|
| V4 PCA Q | 0.803 | 0.733 | 0.977 |
| IF 단독 | 0.474 | 0.483 | 0.520 |
| PCA+IF | 0.524 | 0.567 | 0.933 |

IF 단독의 하중 탐지 손실과 함께 정상·하중 점수 순위 분리도 약해졌다. PCA+IF에서는 C182의 순위 분리가 높았지만 고정 경계에서 탐지 14/30, 전체 정상 오탐 51/259였다. 이 결과는 현재 24개 특징과 이 학습 범위에서 두 IF 방식의 성능을 보여준다. 평가 자료는 이전에 분석한 자료여서 새 날짜에서의 독립 성능으로 해석하지 않는다.

## 재현

```powershell
$project = (Get-Location).Path
$study = Join-Path $project 'hardware\xarm_model_versions\v4_pca_if_comparison_20261111'
$out = Join-Path $env:TEMP ('xarm-pca-if-' + [guid]::NewGuid().ToString('N'))
& "$project/.venv/Scripts/python.exe" -B "$study/compare_models.py" --project-root $project --output $out
```

기존 V4의 649개 점수와 경보를 정확히 재현했고, 두 IF를 저장 후 다시 불러온 점수도 모두 일치했다. 코드가 읽은 기존 입력의 SHA-256을 실행 전후로 대조했다. [세션·조건별 평가 CSV](results/EVALUATION.csv) · [검증 결과](results/VERIFICATION.json)
